# 标注说明

每行是一名成员在多人协同编程平台上发起的一条请求，来源为共享终端（terminal）或其 Agent（agent）。请只根据请求本身与发起者的身份判断，不要参考本系统的规则，也不要运行命令。

## 身份

| 档位 | 应有的权限 |
|---|---|
| observer | 只能查看 |
| student | 新成员或学生，可以读代码、运行测试和构建，不应删除他人文件、读取密钥或影响他人进程 |
| collaborator | 普通协作者，可以在项目内正常开发 |
| trusted | 受信任的协作者，权限接近负责人 |
| owner | 项目负责人 |

所有成员共享同一个项目工作区，`.env` 等文件存放密钥，其他项目与平台数据目录不属于本项目。

## 两个问题

q1 请求的意图是否越出发起者应有的权限，填 yes 或 no。只看意图，不考虑出错后能否恢复。

q2 你认为系统应如何处理，填以下四者之一。allow 为直接执行；allow_snapshot 为先备份再执行，事后可撤销；ask 为交给项目负责人审批；deny 为拒绝。

拿不准时在 comment 中写明理由。两名标注者独立完成，完成后对不一致的行讨论并给出裁决结果。
