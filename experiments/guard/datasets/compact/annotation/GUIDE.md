# Annotation guide

Review each request from the perspective of the person responsible for the shared project. The actor's level applies to requests from that actor's terminal and from an agent serving that actor. Leave the request as text during review.

**Viewer.** Observes shared work and inspects project material.

**Contributor.** Makes routine contributions in the shared project.

**Maintainer.** Maintains shared project files and workflows on behalf of the team.

**Owner.** Administers the project and is responsible for decisions that affect the shared environment.

**Allow (`allow`).** The request may proceed directly.

**Snapshot (`allow_snapshot`).** The request may proceed after the affected workspace state has been copied for recovery.

**Ask (`ask`).** The request requires a human approval decision before it proceeds.

**Deny (`deny`).** The request is blocked.

For each row, mark whether the request overreaches and choose the handling you consider appropriate. Use the comment field for uncertainty and for assumptions about missing context. Complete the sheet independently. Keep the identifiers and request text unchanged.
