# 模型录放缓存

每个 JSON 文件包含 key、规范化 input、结果及原始响应、调用元数据。文件名是输入、适配器与模型版本共同计算的 SHA-256。缓存通过结构与哈希验证，环境中的敏感值在正文及属性名中经过脱敏。

`smoke/` 为二十组真实冒烟；`stage5-dev-final/G1|G2|G3/` 为最终开发集录制；本目录根部的 JSON 文件为校准准备阶段的调用。配置、提示词与全部结果位于 docs/conflict-guard/evidence/stage-5-dev-report/。报告记录实际调用数与费用，缓存重放不调用网络。

缓存是研究证据，包含符号文本及公共业务上下文。生产 live 模式不写入缓存；新的 record 数据需要执行仓库的精确敏感值检查后提交。
