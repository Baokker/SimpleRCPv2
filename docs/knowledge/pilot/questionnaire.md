# pilot 问卷

## NASA-TLX

按 0 到 20 评分：脑力、体力、时间压力、完成信心、努力程度、挫败感。

## SUS

使用标准十题 SUS 问卷，使用 1 到 5 的同意程度评分。

## 七点量表

1. 我能理解知识建议为什么出现。
2. 我能判断一张卡片是否适用于当前代码。
3. Agent 使用知识时，我能理解它参考了什么。
4. 知识建议打扰了我的工作。
5. 我愿意在后续项目继续使用这个功能。

## 访谈提纲

- 哪一次建议最有帮助，原因是什么？
- 哪一次建议让你犹豫或误解？
- 你如何决定确认、修改、合并或丢弃？
- 任务前预览和任务后核对是否改变了你的操作？
