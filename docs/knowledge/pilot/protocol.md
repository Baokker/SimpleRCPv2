# 真人 pilot 流程

## 分组

- 3 到 4 组，每组 2 到 3 人。
- 每组完成两轮同构任务，轮次顺序在组间平衡。
- 每轮 40 分钟：5 分钟说明、25 分钟协作、10 分钟问卷与访谈。

## 任务

每轮包含 3 到 4 个代码陷阱。部分陷阱提供已有团队卡片，部分陷阱需要成员在讨论、调试或修改配置时形成新卡片。主持人记录任务开始、知识建议出现、确认、Agent 使用和任务完成时间。

## 主持人脚本

1. 说明编辑器、聊天、Agent 和知识面板的位置。
2. 提醒参与者按平常方式完成任务，不要求主动创建卡片。
3. 只在参与者无法继续时解释操作入口，不解释某张卡片的内容。
4. 结束后收集问卷、访谈和屏幕录制同意状态。
