# 实验三：Agent 复犯

## 研究问题

在同一组构造任务上，比较无知识（C0）、BM25 召回并由 MiniMax-M3 重排后注入（C2）和直接提供目标卡片（C5）时，Agent 是否避开陷阱。分析把知识送达与行为遵守分开报告。

## 冻结条件与样本

正式运行使用标签 `knowledge-exp-freeze-v3.1`，平台提交 `f0c20bd431024cd900243f73c27b9bbdcccaf947`，数据提交 `ea11a85ed344c522fe3b63288cd8577c94fa6498`，manifest SHA-256 为 `3e536a77fb0724316e10fee1bf9d0d409f88caf57b13e0a7a189c9a339950137`，配置哈希为 `1251aac44831146db92c9adb574fedb933cfcc2928164e6ec8f5ded51540d0ef`。Agent 与知识模型均为 `minimax / MiniMax-M3`，OpenCode 为 `1.18.31`，Node.js 为 `24.7.0`。

22 个任务（16 个陷阱、6 个对照）在三个条件下各运行 3 次，共 198 条记录。所有记录状态为 `completed`，结果键唯一，实验运行器没有额度错误。结果文件为 `runs/exp3-freeze-v31/results.jsonl`，SHA-256 为 `8902d726b9e832f9b54c64035e2808178b49993b7f3251d6692ce89b45535d40`。

| C2 - C5 | 联合成功 | 0 个百分点 | [-18.75, 18.75] | 1.00000 | 1.00000 |

## 结论边界

C2 相对于 C0 的端到端联合成功率差值为 62.5 个百分点，配对检验通过；C5 相对于 C0 的结果相同，说明在这些构造任务中，知识送达后具有明显行为收益。C2 与 C5 的多数结果相同，当前样本没有显示检索注入低于目标卡片直接注入。C2 两次运行级送达失败和 C5 的直接提供条件仍然说明，检索质量与送达是独立的测量环节。结果只适用于固定任务、卡片集合、MiniMax-M3 与冻结配置。
