## 2. 已有结果的使用范围

- E1：两段半合成脚本、52个知识时刻，精确率81.25%、召回率100%。密集讨论与 magic number 的精确率分别为50%、33.33%，这两类提示的人工负担需要在用户实验中观察。
- E2：1440条轨迹，每条比较五种策略。1200条可定位轨迹中，yjs-multi 精确存活率83.42%，multi-strategy 为62.08%。yjs-multi 错误迁移率0.25%，复核请求率16.33%。该结果可以保留。
- E3：历史 BM25 前五名目标命中11/16，bounded 为5/16。实际知识段与 M3 重排的结果使用本轮独立目录，最终判断依据完整矩阵。
- E4：已有114次 M3 运行，尚未覆盖完整任务集。C5 的18次陷阱运行均收到目标卡片，18次避开陷阱、17次联合成功；C2 的21次陷阱运行目标送达为零。这批 C2 使用 legacy 词法评分，不能代表 BM25 或 M3 重排。
- E5：正式矩阵未开始。现有 M2 试跑四个组合仅用于通道检查。
- E6：同一个真实纠正 episode 的三次 M3 服务端验收均结构合法、引用可解析。这是通道验收，不能代替跨 episode 的规则质量评价。

## 3. E4 的建议条件与规模

建议主要比较保留四个条件：C0 无知识、C1 静态 AGENTS.md、C2 经本轮验证选定的检索方式、C5 目标卡片直接提供。22个任务，每条件三次，共264次 Agent 运行。

三个核心问题分别为：C2 相对 C0 是否改善任务表现；C2 相对 C1 是否体现按任务提供知识的价值；C5 与 C2 之间还存在多少送达改进空间。

C7 的已有记录用于描述无关文本条件的观察。本轮若不补齐 C7，就不报告正式等价结论，也不声称已经排除了所有上下文长度效应。C6 过期与矛盾条件作为后续可靠性专题，不加入本轮主要矩阵。C3、C4 保留此前没有主动工具调用的观察。

主表报告陷阱任务联合成功、目标送达、送达子集复犯、对照功能通过，以及费用与耗时。送达子集受到任务难度与检索选择的影响，其条件比例只能用于解释，不单独作为知识的因果效果。

三次重复按原任务聚合，保留逐次数据；正式检验以任务为单位。已有114次结果保留为独立历史批次，新的完整矩阵使用一致代码、配置和运行时段。是否复用其中未改变条件的记录需要在执行前确认，不能直接与新条件混合后忽略批次差异。

## 4. E5 与 E6 共用证据

E5 建议比较 T0 无纠正知识、T1 原始纠正材料、T3 人工确认后的纠正卡片。六个迁移对，每对预定三次 Ta，共18个原始 episode；每个 episode 用同一份 Ta 输出与同一次纠正，分别派生三个 Tb 条件，共54次 Tb 运行。

18次 Ta、纠正过程、草稿生成及54次 Tb 分别统计请求数和费用。Ta 没有踩坑也保留，不反复运行直到获得所需结果；主分析使用实际踩坑子集，另报告全部预定样本。共同证据能使三个条件之间的差异具有可比性。

三个条件均在独立工作区与会话中执行 Tb，发起成员与 Ta 不同。当前只验证确认后跨成员使用；等待60秒不足以证明长期保持，因此不把固定等待单列成长期实验。

T3 保存模型原稿与人工确认后的内容、修改字段和时间。建议由人工依据原始证据确认；gold 卡片仅用于评价。现有工具会在缺少指定标识符时使用 gold 内容，若继续采用该规则，实验只能评价该预定确认规则下的效果，无法归因于自动复盘自身。

E6 共用这些 episode，比较普通草稿与服务端复盘两种方式，每个 episode 各一份，共36份预定草稿，其中 T3 的原始复盘可以复用。两名标注者独立评价规则正确性与可检查性，结构、引用与检查验证作为质量诊断。Agent 自我复盘可以作为扩展比较，当前不增加第三份主矩阵。

## 5. 后续执行次序

1. 完成本轮 E3，依据目标提供、无关知识与实际等待时间选择 C2 的配置。
2. 审阅 E4 四条件设计，以及 E5 共用 episode、T3 人工确认方式，固定配置和判定规则。
3. 执行 E4，完整保留失败与功能退化记录。
4. 执行 E5，同时生成 E6 的普通草稿与复盘原稿，并交给两名标注者独立评分。
5. 更新各实验报告与论文材料事实表。真人 pilot 另行安排，用于观察入口可发现性、确认负担与协作中的实际使用。

现有 E1、E2 的确定性结果继续保留。E3 的结论仅覆盖当前构造任务与措辞改写；任务级重复和改写不增加独立任务样本量。跨项目适用性与真实协作体验仍需独立证据。
