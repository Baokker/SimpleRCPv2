# Agent 会话与交互

My Agent 展示当前成员自己的会话、任务、实时活动与推理文本。个人任务详情、轨迹读取和轨迹下载只允许属主访问，WebSocket 也按成员发送。Chat 中的团队 Agent 任务供项目成员共同查看。

助手正文随着 OpenCode 的消息增量更新显示。工具执行期间已经输出的说明继续可见，取消或失败后也保留已接收的正文。任务完成后显示完整内容，每个正文片段只显示一次。用户提示、推理文本与子任务正文分别处理。实时任务状态直接使用 WebSocket 的任务更新。

每个个人会话分别保存尚未发送的提示与所选文件，切换个人会话或切换到 Chat 后继续保留。发送请求期间继续输入的新文字也会保留。中文输入法确认文字时不会发送任务。阅读较早的消息时，新输出保持当前阅读位置；位于消息列表末尾时自动跟随更新。

每个个人会话页签提供关闭按钮。确认删除后，服务端取消该会话的活动任务，页面移除会话。已经写入的文件继续保留，任务记录与轨迹留在项目元数据中，供审计使用。

向同一会话发送新要求时，服务端取消之前的活动任务，记录中断关系，再调度新要求。新任务使用当前文件内容继续执行。不同会话保持并发执行。Chat 中再次提及同一个团队 Agent，也会中断该 Agent 当前的任务。

任务在准备 OpenCode 连接期间也可以取消。取消状态在连接准备完成后检查，取消的任务不会发送提示。

OpenCode 的 `question.asked` 会在 My Agent 或对应 Chat 任务中显示问题、选项和补充回答输入框。任务发起者可以发送回答或跳过问题，状态显示“等待你的回答”；其他团队成员看到回答者姓名与等待状态。问题支持单选、多选及自由输入，以 OpenCode 提供的字段为准。等待回答期间暂停任务超时计时。问题等待上限为五分钟，取消任务、删除会话和关闭服务时也会结束待回答的问题。

工具执行期间显示工具名称、参数和持续时间，长时间执行时提示“工具仍在执行”。等待模型输出时显示模型等待时间。已经收到的正文和推理文本继续保留。

My Agent 与 Chat 使用同一个“工作详情”组件，包含流式推理文字、工具操作和任务记录。运行中默认展开，收起后显示最近三行推理预览；任务结束后默认收起，重新展开可以阅读推理与操作记录。任务状态、耗时、等待提示和取消按钮显示在工作详情外面。

发送回答与跳过问题分别显示确认提示。关闭待回答问题时，任务状态写入与问题拒绝分别执行，文件写入失败会记录诊断，问题清理仍然继续。

集成使用 OpenCode 1.18.31 的 `question.reply`、`question.reject` 和 `session.abort`。请求通过已安装 SDK 发出。

OpenCode 服务进程设置 `OPENCODE_ENABLE_QUESTION_TOOL=true`。`openCodeQuestions.integration.test.ts` 启动已安装的 OpenCode，查询实际工具列表与待回答问题列表，检查 question 工具可用；该检查不创建模型任务。

## 人工检查

1. Alice 与 Bob 在两个浏览器中加入同一项目，各启动一个个人任务。My Agent 仅显示自己的运行内容；在 Chat 提及团队 Agent 时，团队任务仍共同可见。
2. 在同一个个人会话中发送“用中文编写 README”，随即发送“改为使用法文”。第一项任务显示中断，新任务按法文要求继续。已经完成的文件修改继续保留。
3. 让 Agent 在修改前使用 question 工具询问一项选择。点击选项并发送回答，确认任务继续；也可以跳过问题或取消任务。
4. 点击会话标题旁的关闭按钮并确认。刷新页面后，该会话不再显示，已经写入的文件仍然存在。
5. 在两个个人会话中分别输入不同要求，切换会话及 Chat，确认各会话的文字和所选文件保留。中文输入法确认文字后，任务保持未发送状态。
6. 任务执行期间观察正文逐步出现，向上滚动阅读后确认新消息保持当前阅读位置。取消任务后，已经显示的正文继续保留。

## 验证

`agentPrivacy.test.ts` 通过真实 HTTP、文件存储与服务重启检查个人任务详情、轨迹下载权限及会话删除状态。`verify-agent-acceptance.mjs` 通过两个浏览器与真实 DeepSeek 任务检查问题回答、权限限制、停止、中断和文件结果。

相关文件为 `agentVisibility.ts`、`agentQuestions.ts`、`agentSessionStore.ts`、`agentSessionAccess.ts`、`agentRunManager.ts`、`openCodeRuntime.ts`、`agentRoutes.ts`、`realtime.ts`，以及客户端 `AgentPanel.tsx`、`AgentQuestions.tsx`、`AgentRunProgress.tsx` 和 `CollaborationPanel.tsx`。
