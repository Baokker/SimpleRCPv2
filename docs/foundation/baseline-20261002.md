## OpenCode 配置调查

当前安装版本为 `1.18.31`。SDK 类型包含 `permission.external_directory`，当前配置可以使用 `deny`。`AgentConfig.permission` 支持按 agent 配置规则；`SessionCreateData.body.permission` 与 `SessionUpdateData.body.permission` 支持创建与更新 session 的 `PermissionRuleset`。后续 B3 可以使用这些接口配置任务权限。
