## OpenCode 配置调查

当前安装版本为 `1.18.31`。SDK 类型包含 `permission.external_directory`，当前配置可以使用 `deny`。OpenCode 权限配置按工具规则设置，文档与当前类型没有提供按 session 或按 agent 单独配置 permission 的接口；后续 B3 需要由 SimpleRCPv2 在任务调度与服务端审批层实现更细的控制。
