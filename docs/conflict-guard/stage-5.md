# 阶段 5：灰区模型研判

## 产品接口

`src/adjudication/` 提供 FastJudge、DeepJudge、适配器注册、共享上下文、提示词、截止时间、取消与缓存。模型结果通过 PairCoordinator 生效。full 模式中的灰区进入 analyzing，相关文件暂停写入，文本继续同步；客户端显示黄色区域、解释、建议、来源、置信度、延迟与费用。

默认快判为 Jev `jev-1.13.0`，深判使用配置中的 DeepSeek 模型。T1 关闭 thinking，验证 JSON 和响应 model。OpenAI compatible 同时提供深判与快判角色。快判使用 allow、warn、lock 的 logprobs 条件概率；端点不支持时采用 temperature 1 的单词采样，默认七次。temperature 0 的能力检查响应只计 token。当前环境没有额外兼容端点，X3b 的外部冒烟待补。

G0 返回 warn；G1 使用深判；G2 使用快判；G3 在低置信度、lock 或失败时升级；G4 按时点配置角色。T1 总预算为 8000 ms，2000 ms 后显示分析进度。失败降级为 warn。相同请求共用一次 HTTP 调用，订阅者分别保留时间预算；revision 改变中止旧订阅。

共享上下文收集调用点、所在函数签名、测试断言、修改前注释与返回值使用方式。索引穿透变量别名和重导出，测试断言限定为引用修改符号或其调用方的内容。每侧至多三个调用点，各文本字段至多 3000 字符，invariants 可关闭。产品与实验使用同一个输入构造函数。

缓存身份包含输入、角色、适配器、模型、提示词全文与请求参数，包括 endpoint、temperature、reasoning、hardDeadlineMs。provider_call 保存 cacheKey，full 模式的 replay:check 从缓存恢复模型判定，核验判定、闸门、文件写入与冻结。轨迹只记录元数据，原文保存在经过敏感值过滤的录放缓存。

283 个非 alias 样本完成探针标注，剔除七个。开发集有 101 个有效样本，完整四状态程序去重后评价 79 个：lock 22、allow 57。保留集完成生成与标注，策略评价没有使用保留集。项目、算子、原始探针与程序哈希见 benchmark.md 和 D1-v2 归档。

## 使用限制与后续评价

静态上下文无法完整表示动态共享状态和间接行为，探针也受输入与断言范围限制。当前开发集的最终灰区校准样本只有冲突标签，置信度不能直接解释为正确率。实时模型会对相同输入产生不同结论，正式重现使用固定录制。

数据、模型版本、提示词、价格和阈值均保存于配置或清单。价格日期为 2026-10-06，取消请求可能产生未返回 usage 的费用。阶段 7 可复用 ActorRef、GuardConflict、defer 权限处理和持久通知，保持人类编辑优先。正式保留集评价应在配置冻结后执行。
