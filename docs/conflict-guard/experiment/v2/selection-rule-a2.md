# 阶段 A2 灰区策略选择规则

登记日期：2026-10-17
数据范围：D1-v4 开发集灰区；保留集不参与任何选择。
登记时点：在阶段 A2 新录制与离线阈值计算之前。

## 主指标

系统决定为 `lock` 时记作阳性，`warn` 与 `allow` 均记作阴性。主指标为平衡准确率：

`(冲突拦截率 + 安全修改未拦截率) / 2`

同时报告漏阻断率、安全修改误拦率、冲突通知率（拦截或提醒）、安全修改提醒比例、三分类一致率。质量分母使用 P3 在开发集上进入灰区的全部变更对；未获得有效研判的变更对按实际系统结果计入质量指标。

按变更对统计研判完成率：在灰区变更对中，获得可解析模型判定的变更对比例。语法不完整、模型请求无有效结果、缓存缺项均不算完成。分母为全部进入灰区的变更对。

## 候选与顺序

按以下登记顺序比较：

1. G2：现有 Jev 三分类结果。
2. G2p：原有 Jev 判定标准的概率阈值结果，按下方 16 组阈值依序比较。
3. G2p-new：新 Jev 判定标准的概率阈值结果，按下方 16 组阈值依序比较。
4. G3a：先应用新判定标准下按本文件选择顺序排名最高且通过筛选的阈值组合；Jev 结论为提醒时并行请求 MiniMax-M3 深判，深判有效结果更新结论，超时或格式无效时保留提醒。若新判定标准下没有通过筛选的阈值组合，不计算 G3a。

阈值组合依 `τ_allow` 从小到大、同组内 `τ_lock` 从小到大排列：

| `τ_allow` | `τ_lock` |
|---:|---:|
| 0.05 | 0.50, 0.60, 0.70, 0.80 |
| 0.10 | 0.50, 0.60, 0.70, 0.80 |
| 0.15 | 0.50, 0.60, 0.70, 0.80 |
| 0.20 | 0.50, 0.60, 0.70, 0.80 |

所有组合均满足 `τ_allow < τ_lock`。当 `p_lock >= τ_lock` 时拦截；当 `p_lock < τ_allow` 时放行；其他情况提醒。Jev 原始三分类结果单独保留，供 G2 基线比较。

G1 与阶段 A 已有 G3 只作为背景对照，不参加阶段 A2 的选择。

## 选择顺序

1. 按变更对计的研判完成率低于 95% 时排除候选。
2. 安全修改误拦率超过 15% 时排除候选。
3. 在剩余候选中选择平衡准确率最高者。
4. 平衡准确率相差不超过 2 个百分点时，选择安全修改提醒比例较低者。
5. 仍相同时，选择快判时延 p50 较低者；仍相同则按上述登记顺序。

若候选集合为空，停止并汇报，不临时调整门槛。平衡准确率 75% 是结果目标，只用于判断是否达标，不参与候选排序。

## 统计口径

- 冲突真值为 `lock`；安全修改真值为 `allow`。
- 冲突通知率为冲突样本中最终结果为 `lock` 或 `warn` 的比例。
- 安全修改提醒比例为安全样本中最终结果为 `warn` 的比例。
- 三分类一致率按 `allow`、`warn`、`lock` 的最终结果与可执行探针标签完全相同计算；真值不含 `warn` 时，模型给出的 `warn` 会计为三分类不一致。
- 研判完成率按变更对计；模型请求有效率另按请求计，并同时报告。
- 时延分别报告 Jev 快判与深判确认；费用、调用次数、无 usage 的请求分别报告。
- 每项指标同时提供分子与分母。平衡准确率的两类召回率也单列，避免小样本合成数掩盖任一类别表现。

## 口径修订

本文件修订阶段 A 的选择口径及原 T03 三分类一致率不低于 80% 的门槛。开发集真值只有 `lock` 与 `allow` 两类，三分类一致率会把所有 `warn` 都计为错误，无法单独体现冲突拦截与安全修改放行的平衡情况。阶段 A2 以平衡准确率不低于 75% 作为结果目标，并以安全修改误拦率不超过 15% 作为目标；选择规则按本文件第 3 节执行。旧三分类一致率保留为补充结果，历史阶段 A 结果不改写。
