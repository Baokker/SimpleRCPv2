# 阶段 A3 灰区策略选择规则

登记日期：2026-10-17。数据范围：D1-v4 开发集灰区；保留集不参与选择。

本文件在本轮新录制和离线阈值计算之前登记。它取代 `selection-rule-a2.md` 中的候选名单与选择顺序，主指标、质量门槛和统计口径保持不变。

## 主指标

系统决定为 `lock` 时记作阳性，`warn` 与 `allow` 均记作阴性。平衡准确率为：

`(冲突拦截率 + 安全修改未拦截率) / 2`

同时报告漏阻断率、安全修改误拦率、冲突通知率（拦截或提醒）、安全修改提醒比例、三分类一致率。平衡准确率不低于 75%、安全修改误拦率不超过 15% 是结果目标。

## 候选

按以下登记顺序比较：

1. `G2-v5`：使用 `pair-v5` 的 Jev 直接三分类结果。
2. `G2p-v5`：使用 `pair-v5` 的 Jev 概率与固定阈值网格。阈值组合共 16 组。
3. `G3a`：先使用 `G2-v5`。快判结果为提醒时，并行请求开启推理的 `MiniMax-M3` 深判；深判在时限内返回有效结果时更新结论，超时或格式无效时保持提醒。

旧判定标准 `pair-v4` 的 `G2` 与 `G2p` 只作对照，不参与选择。阶段 A2 已记录它们的结果，本轮输入经过流水线修复后重新生成的结果只用于比较。

阈值组合依 `tau_allow` 从小到大、同组内 `tau_lock` 从小到大排列：

| `tau_allow` | `tau_lock` |
|---:|---:|
| 0.05 | 0.50、0.60、0.70、0.80 |
| 0.10 | 0.50、0.60、0.70、0.80 |
| 0.15 | 0.50、0.60、0.70、0.80 |
| 0.20 | 0.50、0.60、0.70、0.80 |

所有组合满足 `tau_allow < tau_lock`。当 `p_lock >= tau_lock` 时拦截；当 `p_lock < tau_allow` 时放行；其他情况提醒。

## 选择顺序

1. 模型请求有效率低于 95% 的候选排除。`G3a` 的快判与深判分别计算，两个结果都必须达到 95%。模型请求有效率为时限内返回格式有效的请求数除以全部请求数，超时与格式无效请求计入分母。
2. 安全修改误拦率超过 15% 的候选排除。
3. 取平衡准确率最高者。
4. 平衡准确率相差不超过 2 个百分点时，取安全修改提醒比例较低者。
5. 仍相同时，取快判时延 p50 较低者，再按登记顺序。

按变更对计的研判覆盖率不参与选择，作为流水线指标单独报告，并列出未覆盖变更对的原因分类。

候选集合为空时停止并汇报。平衡准确率 75% 只用于判断是否达标。

## 统计口径

- 冲突真值为 `lock`；安全修改真值为 `allow`。
- 冲突通知率为冲突样本中最终结果为 `lock` 或 `warn` 的比例。
- 安全修改提醒比例为安全样本中最终结果为 `warn` 的比例。
- 三分类一致率按最终结果与可执行探针标签完全相同计算；真值不含 `warn` 时，模型给出的 `warn` 计为不一致。
- 变更对覆盖率按灰区变更对中获得有效研判的比例统计，单独报告，不参与候选筛选。
- 请求有效率按模型请求统计。`G3a` 分别报告快判请求和深判请求。
- 时延分别报告第一次快判结论和深判确认；费用、调用次数、无 usage 的请求分别报告。
