# 检查点 C 指标与统计方法

本文件的公式依据用户确认的检查点 A、B 指标要求、阶段八实验表和当前实现。工作目录及 CSCW 上级目录没有找到《实验与评价.md》，其第 5、7 节尚未逐项核验；人工确认时需要核对原文。本文与源码均计算 SHA-256。

## 评价单位

D1 使用关系组作为抽样单位，安全孪生与冲突变体分别记录。四状态完整程序的身份为 `SHA256(JSON.stringify([baseline,leftOnly,rightOnly,merged].map(sortedEntries)))`，与现有入口相同。alias 样本不重复计算；相同程序仅计算一次，标签不同即终止。剔除样本不进入质量分母。报告同时给出关系组、有效变体、去重变体和各分母。

D2 的迁移真值与 D1 的可执行标签分别报告。D3 使用任务对作为抽样单位，两个 run 与建议追加执行保留为该任务对的子记录。

## 比例、时长和费用

| 指标 | 定义 |
|---|---|
| 三分类一致率 | 最终 decision 等于 truth 的有效样本数 / 有效样本数 |
| 漏阻断率 | truth=lock 且最终 decision≠lock 的样本数 / truth=lock 的样本数 |
| 误阻断率 | truth=allow 且最终 decision=lock 的样本数 / truth=allow 的样本数；warn 不进入分母 |
| 逃逸率 | truth∈{lock,warn}，冲突合并文本写入持久内容前未收到 warn、lock、T0 或阻止的样本数 / truth∈{lock,warn} 的样本数 |
| 无关系比例 | 没有语义关系的有效样本数 / 有效样本数 |
| 本地决定比例 | 最终由白区或黑区规则决定的变更对数 / 变更对数；没有变更对的样本不贡献分母；P0、P1、P2、P* 为 N/A |
| 规则精确率 | 本规则产生的最终 decision 等于 truth 的样本数 / 本规则具有真值的最终判定数；另报每次 revision 命中次数 |
| 判定延迟 | 判定时间 − 触发时间，触发为批次关闭或闸门检查；冲突与安全分别报告；缺失触发时间另计数 |
| 模型完成率 | 成功形成判定且未降级的研判任务数 / 研判任务数；HTTP 调用与级联任务分别计数 |
| 升级比例 | 使用深判的级联任务数 / 启动快判的级联任务数 |
| 冻结人秒 | 每人的冻结区间取并集，再对所有人求和；结束于解除、活跃修改结束或最后一次合成编辑；另报无人处理至活跃超时的上界 |
| 冻结次数、被冻结编辑数 | 按 pairId:start 去重的区间数；按 edit 计数的反事实输入数 |
| 每小时卡片数 | 按 pairId:revision 去重的 warn、lock、T0 卡片数 / 第一次至最后一次编辑的累计小时数 |
| 判定前暴露窗口 | 第一次提示时间 − 冲突合并文本首次写入时间，仅对提示晚于写入的样本；全程没有提示的逃逸另计数 |
| Agent 任务成功率 | 最终源码通过任务对验收测试的任务对数 / 执行任务对数；同时保留原有项目测试结果 |
| 被拒后自行修正率 | 收到冲突拒绝后，经 Agent 自行改写而获准并通过验收的初始 run 数 / 收到冲突拒绝的初始 run 数；属主采纳建议后的修改单独报告 |
| 撤回量 | guard-revert 改动的块数、字符数与文件数，交叠而跳过的块单独报告 |
| 打扰次数 | 每位属主每张需要处理的卡片或确认通知计一次；轻提示单列；按双方类型及每人每小时报告 |
| 挂起时长 | 审批挂起至 once/reject 回复的时间，按请求和任务对分别报告 |
| 费用 | inputTokens × inputPerMillion / 10⁶ + outputTokens × outputPerMillion / 10⁶；分角色、Agent 与实验合计；未知 usage 单列 |

逃逸检测沿用当前实现：每个变化文件的持久文本都等于该变体 merged 时形成冲突合并态；反事实写入不算真实发生。这个判断无法识别与完整 merged 文本不同的其他中间失败状态，论文结果需要注明此范围。冻结后的录制操作继续执行以保持坐标，同时标记反事实。

分母为零时显示 N/A，保留原始计数。p50/p95 使用 nearest rank，即排序后第 `ceil(p×n)` 个值；没有样本时显示 N/A。模型调用延迟与完整判定延迟分别报告。live 延迟三轮各自报告及合并分布；replay 的记录延迟用于重现，不充当真实重复。

## 统计

比例使用 Wilson 95% 区间，z=1.96。令 p=s/n，中心为 `(p+z²/(2n))/(1+z²/n)`，半宽为 `z×sqrt((p(1−p)+z²/(4n))/n)/(1+z²/n)`。

配对策略以相同样本的判定正确与否构成 exact McNemar。仅左方正确的数量为 b，仅右方正确为 c；双侧 p 值为 `min(1, 2×Σ[k=0..min(b,c)] C(b+c,k)×2^(−(b+c)))`。分母、样本 ID 或关系组不一致时终止比较。

比例与延迟另执行关系组 bootstrap，重复 2000 次，固定种子 20261007。每次有放回抽取同样数量的关系组，保留组内所有安全与冲突变体，计算原统计量。排序后的 2.5% 和 97.5% 分位数构成区间。D3 以任务对代替 D1 关系组；不得把同一任务对的多个 run 当作独立样本。

Holm 按每个实验的全部预注册策略两两比较构成一个检验族；X7 为基线与五种消融的五次比较。排序后的第 i 个 p 值乘 `(m−i)`，再取前缀最大值并限制为 1，显著性水平为 0.05。同一指标的不同算子族结果属于探索分析，单独标注。

重复一致率同时报告：相同输入哈希的三轮 decision 全部相同的比例，以及相同样本三轮最终 decision 全部相同的比例。缓存回放三轮要求排除测量 timing 后 JSON 逐字节一致，错误数与缓存缺失为零；它只说明重现能力。
